# claude-shared

Louis's shared rules for Claude Code, in one place:

- [`CLAUDE.md`](CLAUDE.md): rules common to every repo.
- [`CODING.md`](CODING.md): extra rules for repos that ship code.
- [`NON-CODING.md`](NON-CODING.md): extra rules for repos that store
  documents, research, content or data.

Each repo's `CLAUDE.md` links here, tells the session to read `CLAUDE.md`
plus the set that matches the repo, and adds only what is specific to
that repo.

This repo is public so that any cloud session can read it without
credentials. Keep it to working rules: nothing personal, no client
names, no secrets. The personal profile (`ai_profile.md`) lives in the
private `louisbaudry/ai_profile` repo.
